# Мини-проект: дневник смен водителя

> Источник: https://jobs.arqa.cc/#task (скопировано 08.10.2026). Как требования закрыты, см. [README](../README.md#что-сделано).


Сделайте небольшое приложение «Дневник смен водителя». Стек любой: мобильное приложение, веб или консольный клиент плюс сервер. Можно и нужно пользоваться ИИ-инструментами.

Данные: файл с поездками водителя в формате JSON (пример ниже). Каждая поездка — время начала, время окончания, сумма, способ оплаты (наличные/карта), комиссия.

## Что должно работать

- Сервер отдаёт по API список поездок за выбранный день и сводку за день: число поездок, выручка, комиссия, «на руки», разбивка наличные/карта.
- Клиент показывает сводку за день и список поездок, позволяет переключать дни.
- Добавление поездки через API с проверкой данных (сумма > 0, окончание позже начала). Повторная отправка той же поездки не должна создавать дубль.
- Тесты на расчёт сводки и на защиту от дублей.

## Пример данных

```json
[
  {"id": "t1", "start": "2026-10-01T08:10:00+05:00", "end": "2026-10-01T08:32:00+05:00",
   "amount": 2400, "payment": "card", "commission": 360},
  {"id": "t2", "start": "2026-10-01T09:05:00+05:00", "end": "2026-10-01T09:20:00+05:00",
   "amount": 1500, "payment": "cash", "commission": 225}
]
```

## Макет

На странице вакансии клиент нарисован как кассовый чек: шапка с датой, строки поездок «08:10–08:32 карта … 2 400 ₸», пунктир, итоги (поездок, выручка, комиссия −585 ₸, наличные / карта), пунктир, крупное «На руки 3 315 ₸». Палитра и шрифты взяты оттуда: бумага `#FFF8E1`, текст `#2B2618`, акцент `#2D5BE3`; JetBrains Mono, Golos Text, Unbounded.
